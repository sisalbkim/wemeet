이메일 문구 모음

화면설계서 작성용으로 이메일 입력과 인증 과정에서 보일 수 있는 문구를 한 화면에 정리했습니다.

브라우저 입력 안내

이메일 입력칸에서 형식이 맞지 않을 때
형식 안내 `@` 문자를 포함해 주세요.
형식 안내 올바른 이메일 형식을 입력해주세요.
예시 안내 예: `user@example.com`

회원가입 이메일 확인

이메일 중복확인과 인증 과정에서 표시되는 문구
기본 안내 이메일 중복 여부를 먼저 확인해주세요.
중복확인 성공 사용 가능한 이메일입니다.
중복확인 실패 이미 사용 중인 이메일입니다.
중복확인 오류 이메일 중복확인 중 오류가 발생했습니다.

이메일 인증

인증코드 전송과 확인 단계에서 표시되는 문구
인증 필요 이메일 인증이 필요합니다.
전송 완료 인증코드를 전송했습니다.
전송 오류 인증코드 전송 중 오류가 발생했습니다.
입력 누락 이메일과 인증코드를 모두 입력해주세요.
전송 선행 필요 먼저 이메일 중복확인을 하고 인증코드를 전송해주세요.
인증 실패 인증코드가 일치하지 않습니다.
인증 완료 이메일 인증이 완료되었습니다.
인증 상태 유지 이메일 인증이 완료된 상태입니다.
인증 오류 이메일 인증 확인 중 오류가 발생했습니다.
회원가입 제한 이메일 중복확인과 이메일 인증을 먼저 완료해주세요.

계정 찾기

이메일을 사용하는 계정 조회 단계에서 표시되는 문구
아이디 찾기 이름과 올바른 이메일 형식을 입력해주세요.
아이디 찾기 이름과 이메일이 일치하는 계정을 찾지 못했습니다.
비밀번호 찾기 이름, 아이디, 올바른 이메일을 입력해주세요.
비밀번호 찾기 이름, 이메일, 아이디가 일치하는 계정을 찾지 못했습니다.
비밀번호 찾기 임시 비밀번호를 메일로 보냈습니다.
